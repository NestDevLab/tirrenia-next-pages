# Tirrenia Next

Public GitHub Pages deployment bundle for Tirrenia Next at
`next.tirrenia.eu`.

The editable source remains in the private Tirrenia project. This repository
contains generated static files only.

Current source: `NestDevLab/tirrenia-next` PR #5, commit
`b47ca9011a914c0c12a1dd1dba8cec12afa02e02`. The Club, subrent and sale
forms send non-binding requests to the same-origin Cloudflare Worker; no
booking, price or payment is confirmed by these pages.
